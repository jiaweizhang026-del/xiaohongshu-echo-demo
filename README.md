# 回声 Echo

小红书产品设计团队体验设计测试题 - 「互动」方向纯前端交互原型。

## 核心命题

今天社区里的互动大多围绕内容：点赞、收藏、评论。用户知道“这篇内容被很多人看见”，却很难感到“此刻有人和我一样”。

「回声」把用户在一句内容前的停留，变成一次低压力、可结束的陌生人连接：

1. 在笔记中看到“也停在这里的人”
2. 选择当下感受
3. 匿名匹配一位选择相近感受的人
4. 交换一轮回声，关系自然结束

## 设计边界

- 不开放持续私聊，避免陌生社交压力
- 不强迫关注或互关，关系可以只发生一次
- 回声默认匿名且不公开展示
- 原型不使用后端，演示数据均为本地模拟

## 本地运行

项目为零依赖纯前端，直接打开 `index.html` 即可；也可用任意静态服务器：

```bash
npx serve .
```

## 技术说明

- HTML / CSS / Vanilla JavaScript
- 响应式布局：桌面端为方案说明 + 手机原型，移动端直接进入原型
- 使用 `localStorage` 模拟“收进回声夹”和最近一次回复
- 无网络请求、无后端服务、无第三方依赖，适合 REDcowork 纯前端部署

## AI / Coding 工具使用说明

AI 用于辅助拆解题目、梳理交互状态、生成前端基础代码与测试清单；核心洞察、机制取舍、信息架构、文案和最终体验由设计判断完成。AI 没有用于“替用户表达”，也没有进入匹配与关系决策，以免削弱真实感受的价值。
